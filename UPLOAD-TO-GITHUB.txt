How to publish
--------------
OPTION A - easiest with your local project
1. Make a backup of your current ARVION / arvion-website folder.
2. Copy everything from this TUSOROVA-redesign folder into your existing repo folder.
3. Replace files when Windows asks.
4. Open PowerShell inside the repository.
5. Run:

   git add .
   git commit -m "Redesign TUSOROVA marketplace"
   git push origin main

6. GitHub Pages will publish the updated files from your main branch.
